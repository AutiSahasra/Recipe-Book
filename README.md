# 🍳 Recipe Book

A simple **Recipe Book web application** built using **HTML, CSS, and Vanilla JavaScript**.

This project was created as a hands-on frontend revision project to refresh my fundamentals and understand how different frontend concepts work together in a real application.

## 🚀 About the Project

The application allows users to search for recipes and view recipe information through an interactive interface.

I intentionally built this project **without React or any frontend framework** so that I could strengthen my understanding of frontend fundamentals.

## 🛠️ Tech Stack

- HTML5 – Structure and content
- CSS3 – Styling and layout
- JavaScript – Logic, DOM manipulation and interactivity
- DummyJSON Recipes API – Recipe data


## 📚 What I Learned

### HTML

- Semantic HTML
- Forms and input elements
- IDs and classes
- Linking CSS and JavaScript files
- Structuring a webpage

### CSS

- CSS selectors

### JavaScript

- Dynamic HTML generation

## 🌐 Application Flow


User enters a recipe
        ↓
Form submission
        ↓
preventDefault()
        ↓
Get search input
        ↓
Call Recipe API
        ↓
Receive JSON response
        ↓
Process the data
        ↓
Generate recipe cards
        ↓
Display results'
